===============================================================================
                        TRANSACTION FLOW
===============================================================================

                    Generate Receipt Transaction
                    ═══════════════════════════

START
  │
  ├──► BEGIN TRANSACTION
  │
  ├──► Step 1: Generate unique invoice number
  │         └─► Format: INV-YYYYMMDD-XXXX
  │
  ├──► Step 2: Validate all items
  │         ├─► Check each product exists
  │         ├─► Check sufficient stock
  │         └─► Calculate totals
  │
  ├──► Step 3: Insert receipt header
  │         └─► receipts table
  │
  ├──► Step 4: For each item in cart:
  │         ├─► Insert into receipt_items
  │         ├─► Insert into purchases
  │         ├─► Update inventory (reduce stock)
  │         └─► Calculate profit
  │
  ├──► Step 5: Verify all operations
  │         └─► Check constraints satisfied
  │
  ├──► COMMIT TRANSACTION ✓
  │
  └──► Return invoice_number

ERROR at any step → ROLLBACK TRANSACTION → Return error

===============================================================================
                        KEY ALGORITHMS
===============================================================================

1. INVOICE NUMBER GENERATION
─────────────────────────────
   Input: None
   Output: Unique invoice number
   
   Algorithm:
   1. Get current date (YYYYMMDD format)
   2. Generate random 4-digit number (1000-9999)
   3. Format: "INV-{date}-{random}"
   4. Check if exists in database
   5. If exists, try again (max 100 attempts)
   6. If all taken, use timestamp
   7. Return invoice number


2. STOCK VALIDATION
───────────────────
   Input: product_id, quantity
   Output: Boolean (valid/invalid)
   
   Algorithm:
   1. Query database for product
   2. If not found → return False
   3. Get available stock
   4. If quantity > stock → return False
   5. Return True


3. PROFIT CALCULATION
─────────────────────
   Input: quantity, selling_price, stock_price
   Output: profit amount
   
   Algorithm:
   profit = (selling_price - stock_price) × quantity
   
   Example:
   - Quantity: 10
   - Selling: $5.00
   - Stock: $3.00
   - Profit: ($5.00 - $3.00) × 10 = $20.00


4. CART TOTAL CALCULATION
─────────────────────────
   Input: List of cart items
   Output: Total amount
   
   Algorithm:
   total = 0
   for each item in cart:
       item_total = item.quantity × item.price
       total = total + item_total
   return total


===============================================================================
                        SECURITY FEATURES
===============================================================================

✓ SQL Injection Prevention
  - Parameterized queries used everywhere
  - No string concatenation in SQL

✓ Input Validation
  - All user inputs validated
  - Type checking on all fields
  - Range checking (positive numbers, etc.)

✓ Transaction Safety
  - ACID compliance
  - Rollback on errors
  - No partial updates

✓ Data Integrity
  - Foreign key constraints
  - Unique constraints on invoice numbers
  - Not-null constraints on required fields

✓ Error Handling
  - Try-catch blocks
  - Graceful error messages
  - No data loss on errors
